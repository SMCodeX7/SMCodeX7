## 🚀 Featured Projects

### 🇱🇰 CeylonCompass

**Smart Sri Lanka Travel Recommendation & Route Optimization Platform**

An end-to-end travel planning system combining recommendation systems, weather intelligence, budget modelling, geospatial analysis, and route optimization.

- Built an explainable recommendation engine using **cosine similarity and multi-criteria weighted ranking**
- Integrated **Google OR-Tools, Haversine distance, Open-Meteo, Folium, and OpenStreetMap**
- Evaluated the system using **30 reproducible traveller scenarios**
- Achieved **96.67% modelled budget compliance**, **100% route validity**, and **4.47% mean route-distance saving**
- Built a test suite with **244 automated tests** covering recommendation, optimization, weather, itinerary, budget, evaluation, and integration logic
- Deployed publicly using Streamlit Community Cloud

[Live Demo](https://sm-ceylon-compass.streamlit.app/) · [Repository](https://github.com/SMCodeX7/Ceylon-Compass)
